THE TRUST BOUNDARY

One path.
Two responses.

Third-party API routers unify access to model providers. Their position also gives them plaintext access to the requests and responses that drive agent actions.

The provider can return a benign answer while the agent receives a modified response. The resulting execution can diverge from what the provider intended.

ROUTER-SIDE INTERVENTIONS

Four injection levels.

The study examines four levels of increasing subtlety. Each changes the response delivered to the coding agent.

L1

Response Substitution

The router discards the provider response and delivers an alternative in its place.

L2

Response Append

The original provider response remains visible alongside an additional tool call.

L3

LLM-Polished Injection

The explanation is rewritten to match the modified action.

L4

LLM-Polished with Distribution Alignment

The delivered response is regenerated from a mixture of model output distributions.

EMPIRICAL RESULTS

What the runs showed.

Injection effectiveness across agents

All four coding agents reached 0% DSR at all four injection levels under their commonly used high-permission modes.

DSR measures the share of injected malicious calls denied before execution. Tokens and time are means per turn.

All four coding agents achieved 0% DSR across their evaluated native configurations.

Sensitivity to backend model

Router-side injection achieved 0% DSR across the four backend models tested with Claude Code under L1. Task success rates and execution turns shifted by different amounts across models.

Effectiveness of mitigations

Whitelist control provides a simple, model-free baseline. LLM review can achieve a more favorable balance between DSR and WBR, with results varying by reviewer and injection level.

Higher DSR means more malicious calls were blocked. WBR is the share of all denied calls that were benign.

Results from the controlled evaluation in arXiv:2607.23624v5.

THE CONTROL GAP

Who controls the next action?

Whitelist-based execution control and LLM review do not reliably close the gap between provider output and agent execution. The findings motivate provider-supported output-integrity mechanisms.
